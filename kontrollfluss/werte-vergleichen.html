Werte vergleichen

Ein Rechenausdruck liefert eine Zahl. Mit einem Vergleich prüfen Sie, ob eine Aussage über Werte wahr oder falsch ist.

  • Vergleichsergebnisse
  • Operatoren
  • Selbst programmieren
  • Zuweisung und Vergleich
  • Wahrheitswerte und Grenzen

Lernziele

  • Die sechs Vergleichsoperatoren verwenden und ihre Ergebnisse vorhersagen.
  • Zuweisung und Vergleich unterscheiden.
  • Vergleichsergebnisse speichern, ausgeben und an Grenzwerten prüfen.

1. Was liefert ein Vergleich?

Lesen Sie diesen Ausschnitt aus main. Notieren Sie zunächst die erwartete Ausgabe.

int alter = 19;

printf("Alter im nächsten Jahr: %d\n", alter + 1);
printf("Mindestens 18: %d\n", (alter >= 18));

alter + 1 berechnet eine Zahl. alter >= 18 prüft, ob das Alter mindestens 18 ist. Die Vergleichsoperatoren liefern in C einen Wert vom Typ int: 1 für wahr, 0 für falsch.

Selbstkontrolle: Welche vollständige Ausgabe entsteht?

Genau eine Antwort ist richtig. Kreuzen Sie diese an.

Erklärung anzeigen

Die erste Antwort stimmt. 19 + 1 ergibt 20. 19 >= 18 ist wahr und liefert 1. Beide Ausgaben stehen wegen \n in eigenen Zeilen.

Allgemein gilt für C-Bedingungen: 0 wird als falsch interpretiert, jeder Wert ungleich 0 als wahr. Die hier verwendeten Vergleichsoperatoren liefern jedoch immer genau 0 oder 1. Formulieren Sie Bedingungen zunächst mit ausdrücklichen Vergleichen.

2. Die sechs Vergleichsoperatoren

OperatorBedeutungBeispielErgebnis
==gleich7 == 50
!=ungleich7 != 51
<kleiner7 < 50
<=kleiner oder gleich7 <= 50
>größer7 > 51
>=größer oder gleich7 >= 51

„Mindestens“ und „höchstens“ schließen den Grenzwert ein. „Mehr als“ und „weniger als“ schließen ihn aus.

Welche Vergleiche sind bei int punkte = 10; wahr?

Eine oder mehrere Antworten können richtig sein.

Erklärung anzeigen

punkte >= 10 und punkte == 10 sind wahr. 10 ist gleich 10, aber weder größer noch ungleich.

Kurze Frage: Wie formulieren Sie „höchstens 10 Punkte“?

Antwort anzeigen

punkte <= 10. Auch genau 10 Punkte erfüllen die Bedingung.

3. Programmieraufgabe: Vergleiche untersuchen

Verwenden Sie aus dem Materialarchiv den Ordner 01-vergleiche. Einzeldateien: programm.c und Makefile.

  1. Im Gerüst stehen int a = 7; und int b = 5;. Notieren Sie für alle sechs Operatoren das erwartete Ergebnis.
  2. Ersetzen Sie die mit TODO markierten Nullen in den Ausgaben durch passende Vergleiche. Beispiel: printf("a == b: %d\n", (a == b));
  3. Speichern Sie, übersetzen Sie im Aufgabenordner mit make und starten Sie mit ./programm. Vergleichen Sie mit Ihrer Vorhersage.
  4. Setzen Sie danach beide Variablen auf 5. Welche Ergebnisse ändern sich? Notieren Sie Ihre Vorhersage und überprüfen Sie sie nach erneutem Übersetzen.
Hinweis

Ändern Sie den Vergleich außerhalb der Anführungszeichen. Der Text vor %d ist nur die Beschriftung.

Selbstkontrolle: Ergebnisse

In der Reihenfolge ==, !=, <, <=, >, >=:

  • Für 7 und 5: 0, 1, 0, 0, 1, 1.
  • Für 5 und 5: 1, 0, 0, 1, 0, 1.
Mögliche Lösung der Ausgabezeilen
printf("a == b: %d\n", (a == b));
printf("a != b: %d\n", (a != b));
printf("a < b: %d\n", (a < b));
printf("a <= b: %d\n", (a <= b));
printf("a > b: %d\n", (a > b));
printf("a >= b: %d\n", (a >= b));

4. Zuweisung ist kein Vergleich

int anzahl = 4;
printf("%d\n", (anzahl == 6));
printf("%d\n", anzahl);
anzahl = 6;
printf("%d\n", (anzahl == 6));

== vergleicht Werte, ohne sie zu verändern. anzahl = 6; weist der Variable dagegen einen neuen Wert zu. Bei int anzahl = 4; wird die Variable deklariert und initialisiert, wie im Variablenkapitel.

Welche Aussagen zum Beispiel stimmen?

Eine oder mehrere Antworten können richtig sein.

Erklärung anzeigen

Die Aussagen 1, 2 und 4 stimmen. Die Ausgabe lautet zeilenweise 0, 4, 1. Ein Vergleich verändert die Variable nicht.

5. Wahrheitswerte speichern und Grenzen prüfen

Vergleichsergebnisse können Sie in einer Variable vom bekannten Typ bool speichern. Verwenden Sie dafür #include <stdbool.h>.

int alter = 19;
bool volljaehrig = (alter >= 18);
printf("Volljährig: %d\n", volljaehrig);

Der Vergleich liefert ein int-Ergebnis mit dem Wert 0 oder 1. Die bool-Variable speichert den entsprechenden Wahrheitswert. Mit %d erscheint hier ebenfalls 0 oder 1.

Vorhersage: Welche Ausgabe erwarten Sie für ein Alter von 17, 18 und 19 Jahren?

Antwort anzeigen

Für 17: Volljährig: 0. Für 18 und 19: jeweils Volljährig: 1.

Programmieraufgabe: Zwei Grenzen

Nutzen Sie den Ordner 02-grenzwerte im Materialarchiv. Einzeldateien: programm.c und Makefile.

  1. Ersetzen Sie die markierten false-Werte durch Vergleiche: volljaehrig soll ab 18 Jahren wahr sein. menge_erlaubt soll für höchstens 10 Stück wahr sein. Verwenden Sie zunächst nur nichtnegative Werte.
  2. Prüfen Sie für das Alter die Werte 17, 18 und 19, für die Menge 9, 10 und 11. Notieren Sie die Erwartungen vor jedem Ausführen. Speichern und übersetzen Sie jede Änderung erneut.
  3. Erklären Sie, welchen Fehler Sie mit dem Test genau auf der Grenze erkennen können.
Hinweis

„Ab 18“ bedeutet „größer oder gleich 18“. „Höchstens 10“ bedeutet „kleiner oder gleich 10“.

Mögliche Lösung und Selbstkontrolle
bool volljaehrig = (alter >= 18);
bool menge_erlaubt = (menge <= 10);

Alter 17, 18, 19 ergibt 0, 1, 1. Menge 9, 10, 11 ergibt 1, 1, 0. Genau auf der Grenze unterscheiden Sie zum Beispiel > von >=. Ein Test nur mit 19 würde diesen Fehler nicht aufdecken.

Sie können nun einzelne Werte vergleichen. Als Nächstes verbinden Sie mehrere Vergleiche zu einer Bedingung.
