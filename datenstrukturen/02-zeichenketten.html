Zeichenketten

Text ist in C ein Array von Zeichen mit einem besonderen Endzeichen.

1. Text als Array von Zeichen

Eine Zeichenkette ist ein Array vom Typ char. Hinter dem letzten sichtbaren Zeichen steht das Nullzeichen '\0'. Daran erkennen Funktionen wie printf mit %s, wo der Text endet. Eine Zeichenkette in Anführungszeichen enthält dieses Endzeichen automatisch:

char gegenstand[16] = "Beute";

Vorhersagen und ausprobieren

In den Aufgaben verwenden Sie die Funktion strlen aus der Header-Datei <string.h>. Beide haben Sie bisher noch nicht kennengelernt. Wie Sie eine unbekannte Bibliotheksfunktion verwenden, wissen Sie aber aus dem Kapitel „Manpages und Bibliotheksdokumentation“: Schlagen Sie strlen nach, bevor Sie die Funktion einsetzen. Welche Header-Datei müssen Sie einbinden? Welchen Parameter erwartet die Funktion, und was liefert sie zurück?

Notieren Sie zuerst Ihre Erwartung, dann prüfen Sie im Programm:

  1. Was liefert sizeof(gegenstand)? Was liefert strlen(gegenstand)?
  2. Welches Zeichen steht in gegenstand[4], welches in gegenstand[5]?
  3. Geben Sie den Text Zeichen für Zeichen mit einer Schleife aus, ohne strlen zu verwenden. Woran erkennt Ihre Schleife das Ende?
  4. Lassen Sie die Größe weg: char name[] = "Beute";. Wie groß ist das Array jetzt?
  5. Was liefert strlen für "Tür"? Vergleichen Sie mit "Tuer".
Selbstkontrolle: Ihre Beobachtungen

sizeof liefert die Größe des ganzen Arrays, hier 16. strlen zählt die Zeichen vor dem Nullzeichen, hier 5. In gegenstand[4] steht 'e', in gegenstand[5] das Nullzeichen. Ohne Größenangabe ist das Array 6 Zeichen groß: fünf Buchstaben und das Endzeichen. Für "Tür" liefert strlen meist 4, weil das ü in der üblichen Kodierung UTF-8 zwei Bytes belegt. strlen zählt Bytes, keine Buchstaben. Verwenden Sie für Spieltexte deshalb Schreibweisen wie Tuer.

Gegeben ist char text[10] = "Wache";. Welche Aussagen stimmen?

Eine oder mehrere Antworten können richtig sein.

Erklärung anzeigen

Die ersten drei Aussagen stimmen. Ein Platz wird immer für das Nullzeichen gebraucht. In ein Array mit 10 Zeichen passen deshalb höchstens 9 sichtbare Zeichen.

2. In der Dokumentation nachschlagen

Für Zeichenketten gibt es Bibliotheksfunktionen in <string.h> und <stdio.h>. Wenden Sie an, was Sie im Kapitel „Manpages und Bibliotheksdokumentation“ geübt haben. Schlagen Sie die folgenden Funktionen nach und notieren Sie jeweils Parameter, Rückgabewert und Voraussetzungen:

  • strlen (falls noch nicht in Abschnitt 1 geschehen)
  • strcmp
  • snprintf (steht auf derselben Seite wie printf)

Texte vergleichen

Sie starten Ihr Programm mit Optionen wie ./programm --text. Das Gerüst muss dafür erkennen, welcher Text auf der Kommandozeile stand. Legen Sie in text_ausgeben ein Zeichen-Array mit dem Inhalt "--text" an. Vergleichen Sie es zuerst mit == mit dem Text "--text" und danach mit strcmp. Was meldet der Compiler? Was gibt das Programm aus? Erklären Sie den Unterschied mithilfe der Dokumentation.

Sehen Sie sich anschließend in programm.c die Schleife am Anfang von main an. Wie erkennt das Gerüst die Optionen? Den Ausdruck argv[argument] müssen Sie noch nicht verstehen; er steht für den Text einer Option.

Selbstkontrolle: Vergleich mit == und strcmp

Der Vergleich mit == vergleicht nicht den Inhalt der beiden Texte, sondern prüft, ob beide Seiten dieselbe Stelle im Speicher bezeichnen. Ein Zeichen-Array ist wie jede Variable ein eigener Speicherbereich (siehe Lokale und globale Variablen). Der Text "--text" in Anführungszeichen liegt an einer anderen Stelle. Deshalb ergibt der Vergleich Ihres Arrays mit "--text" immer 0, also falsch, auch wenn der Inhalt gleich ist. Ebenso ergibt der Vergleich zweier verschiedener Arrays mit gleichem Inhalt immer 0. Wahr ist der Vergleich nur, wenn beide Seiten derselbe Speicherbereich sind, etwa wenn Sie ein Array mit sich selbst vergleichen. Wie man mit solchen Speicherstellen arbeitet, lernen Sie im Kapitel „Pointer und Datenaustausch“.

Viele Compiler warnen vor dem Vergleich mit ==, weil er fast nie das ist, was gemeint war. strcmp vergleicht Zeichen für Zeichen und liefert 0, wenn beide Texte gleich sind. Ein Rückgabewert ungleich 0 bedeutet, dass sie sich unterscheiden.

3. Aufgabe: Eine Statuszeile zusammensetzen

Laut Spielbeschreibung aus „Vom Problem zum Programm II“ kann der aktuelle Spielstand zusätzlich als Text ausgegeben werden: Position der Spielfigur, Inventar, verbrauchte Züge und die Zustände von Tür, Tresor und Gegenständen. Als ersten Baustein dafür setzen Sie eine Statuszeile in einem Zeichen-Array zusammen. Sie soll die Position der Spielfigur, die verbrauchten Züge und das Zuglimit enthalten. Verwenden Sie dafür snprintf. Das Format legen Sie selbst fest und notieren es in Ihrer Projektnotiz.

  • Wählen Sie eine Größe für das Zeichen-Array und begründen Sie sie: Wie lang kann Ihre Zeile höchstens werden?
  • Werten Sie den Rückgabewert von snprintf aus. Woran erkennen Sie laut Dokumentation, dass der Text nicht vollständig in das Array gepasst hat?
  • Testen Sie das absichtlich mit einem zu kleinen Array. Notieren Sie vorher, welchen Inhalt Sie erwarten.
  • Bei welchen Werten wird Ihre Zeile am längsten? Nehmen Sie diesen Fall in Ihre Tests auf.
Denkhilfe: Den Rückgabewert deuten

Die Dokumentation unterscheidet zwischen der Zahl der Zeichen, die tatsächlich geschrieben wurden, und der Zahl, die geschrieben worden wäre. Welche der beiden liefert snprintf? Was bedeutet es, wenn dieser Wert mindestens so groß ist wie das Array?

Selbstkontrolle: Ein zu kleines Array

snprintf schreibt höchstens so viele Zeichen, wie in das Array passen, und schließt den Text mit '\0' ab. Zurückgegeben wird die Länge, die der vollständige Text gehabt hätte. Ist dieser Wert größer oder gleich der Arraygröße, wurde gekürzt. Ihre Zeile ist dann zwar ein gültiger Text, aber unvollständig.

Erklärung anzeigen

Die zweite und dritte Aussage stimmen. strcmp liefert bei gleichen Texten 0. strlen zählt nur die Zeichen vor dem Nullzeichen.
