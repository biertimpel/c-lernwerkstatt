Ein Programm auf Header und Quelldateien verteilen

Einen fertigen Rechner in zwei Quelldateien und einen gemeinsamen Header aufteilen.

1. Eine gemeinsame Schnittstelle

Bisher standen Ihre eigenen Funktionen überwiegend in einer gemeinsamen Quelldatei. Wenn ein Programm wächst, können Sie zusammengehörige Funktionen auf mehrere Dateien verteilen.

Eine Funktionsdeklaration beschreibt den Rückgabetyp, den Namen und die Parameter:

int addiere(int a, int b);

Die Funktionsdefinition enthält zusätzlich den Funktionskörper:

int addiere(int a, int b) {
    return a + b;
}

Mehrere Quelldateien können dieselbe Funktion verwenden. Damit wir die Deklaration nur an einer Stelle pflegen müssen, legen wir sie in einer gemeinsamen Header-Datei ab. C-Header haben üblicherweise die Endung .h.

DateiAufgabe
calc.hDeklarationen der Rechenfunktionen.
calc.cDefinitionen der Rechenfunktionen.
main.cEnthält main, ruft die Funktionen auf und gibt Ergebnisse aus.

Der Header beschreibt die Schnittstelle: Welche Funktionen stehen zur Verfügung und wie werden sie aufgerufen? Solange Parameter und Rückgabetyp gleich bleiben, können wir die Berechnung verändern, ohne die Aufrufe anzupassen. An diese Arbeit mit Schnittstellen knüpfen wir später bei der Objektorientierung an.

2. Einen Header einbinden

Mit der folgenden Anweisung binden Sie Ihren eigenen Header ein:

#include "calc.h"

Vor der eigentlichen Übersetzung verarbeitet der Präprozessor solche Anweisungen. Vereinfacht wird dabei der Inhalt des Headers an dieser Stelle eingefügt. Die Deklarationen werden damit für die betreffende Quelldatei verfügbar.

Sowohl main.c als auch calc.c binden den Header ein. Damit überprüft der Compiler die Aufrufe und kann Abweichungen zwischen den Definitionen und den gemeinsamen Deklarationen erkennen.

Für unseren eigenen Header verwenden wir Anführungszeichen. Bibliotheksheader kennen Sie bereits mit spitzen Klammern:

#include <stdio.h>

stdio.h stellt unter anderem die Deklaration von printf bereit. Dessen Implementierung stammt aus der C-Bibliothek.

3. Mehrfaches Einbinden verhindern

Ein Header kann auf verschiedenen Wegen mehrfach eingebunden werden. Ein Include-Schutz sorgt dafür, dass sein geschützter Inhalt während der Übersetzung einer Quelldatei nur einmal verarbeitet wird:

#ifndef CALC_H
#define CALC_H

/* Hier stehen die Funktionsdeklarationen. */

#endif
  • #ifndef CALC_H prüft, ob die Kennzeichnung noch nicht definiert ist.
  • #define CALC_H setzt diese Kennzeichnung.
  • #endif beendet den geschützten Abschnitt.

Bei einer erneuten Einbindung wird der Abschnitt übersprungen. Der Schutz gilt jeweils während der Übersetzung einer Quelldatei. Beide Quelldateien können den Header verwenden.

Die Kennzeichnung ist keine Variable des laufenden Programms. Die Anweisungen werden vor der eigentlichen Übersetzung verarbeitet. Später werden auch gemeinsame Datentypen in Headern stehen, bei denen mehrfaches Verarbeiten zu Fehlern führen kann.

4. Aufgabe A

Der kleine Rechner ist bereits vollständig implementiert. Laden Sie das Startmaterial herunter und entpacken Sie es in einen eigenen Arbeitsordner. Es enthält diese main.c:

#include <stdio.h>

int addiere(int a, int b) {
    return a + b;
}

int multipliziere(int a, int b) {
    return a * b;
}
int main(void) {
    int a = 4;
    int b = 7;
    int summe = addiere(a, b);
    int produkt = multipliziere(a, b);

    printf("Summe: %d\n", summe);
    printf("Produkt: %d\n", produkt);

    return 0;
}
  1. Legen Sie im selben Ordner calc.h und calc.c an.
  2. Verschieben Sie die Definitionen von addiere und multipliziere nach calc.c.
  3. Schreiben Sie die passenden Funktionsdeklarationen in calc.h und ergänzen Sie den Include-Schutz.
  4. Binden Sie calc.h in beiden Quelldateien ein.
  5. Übersetzen und starten Sie das aufgeteilte Programm mit den folgenden Befehlen. Prüfen Sie, ob weiterhin dieselben Ergebnisse ausgegeben werden.
gcc main.c calc.c -o rechner
./rechner

-o rechner benennt die erzeugte Programmdatei. Was beim Bauen genau geschieht, verfolgen Sie auf der nächsten Seite.

Ihr Ergebnis: Der Rechner besteht aus zwei Quelldateien und einem gemeinsamen Header.

Hinweise

Deklaration und Definition zuordnen

Die Deklaration endet nach der Parameterliste mit einem Semikolon. Die Definition enthält zusätzlich den Funktionskörper. Die vorhandenen Berechnungen sind vollständig gegeben.

Die Dateien verbinden

Beide Quelldateien verwenden #include "calc.h". Die Definitionen stehen in calc.c. Diese Quelldatei wird im Übersetzungsbefehl angegeben. Binden Sie dafür keine .c-Datei mit #include ein.

Den Include-Schutz ergänzen

Die Deklarationen gehören zwischen #define CALC_H und #endif. Verwenden Sie für jeden eigenen Header eine passende eigene Kennzeichnung.

Selbstkontrolle

Eine mögliche Aufteilung

calc.h

#ifndef CALC_H
#define CALC_H

int addiere(int a, int b);
int multipliziere(int a, int b);

#endif

calc.c

#include "calc.h"

int addiere(int a, int b) {
    return a + b;
}

int multipliziere(int a, int b) {
    return a * b;
}

main.c

#include <stdio.h>
#include "calc.h"

int main(void) {
    int a = 4;
    int b = 7;
    int summe = addiere(a, b);
    int produkt = multipliziere(a, b);

    printf("Summe: %d\n", summe);
    printf("Produkt: %d\n", produkt);

    return 0;
}
