Den Build mit einem Makefile ausführen

Bekannte Übersetzungsbefehle mit make ausführen und die Dateistruktur im Spielgerüst wiedererkennen.

1. Befehle und Abhängigkeiten festhalten

Mit mehreren Quelldateien gehören mehrere Befehle zum Bauen. Ein Makefile hält fest, welche Dateien voneinander abhängen und welche Befehle sie erzeugen.

Eine Regel besteht aus einem Ziel, seinen Voraussetzungen und einem Befehl. Die Befehlszeile beginnt mit einem Tabulator.

make prüft die angegebenen Abhängigkeiten. Fehlt die Zieldatei oder ist eine Voraussetzung neuer, führt es die zugehörigen Befehle aus. make ruft dafür beispielsweise gcc auf. Die Übersetzung selbst erledigen weiterhin die Übersetzungswerkzeuge.

2. Aufgabe C

Laden Sie das vorbereitete Makefile in Ihren Arbeitsordner. Die Datei heißt Makefile ohne zusätzliche Endung. Ihr Inhalt lautet:

rechner: main.o calc.o
	gcc main.o calc.o -o rechner

main.o: main.c calc.h
	gcc -c main.c -o main.o

calc.o: calc.c calc.h
	gcc -c calc.c -o calc.o

Ohne weitere Angaben bearbeitet make hier das erste Ziel rechner. Dazu prüft es zunächst die Objektdateien und deren Voraussetzungen.

  1. Ordnen Sie in der Regel für main.o Ziel, Voraussetzungen und Befehl zu.
  2. Entfernen Sie die drei erzeugten Dateien main.o, calc.o und rechner. Führen Sie make und danach ./rechner aus.
  3. Rufen Sie unmittelbar danach erneut make auf. Wird nochmals übersetzt oder gelinkt?
  4. Verändern Sie in calc.c die Funktion addiere wie unten gezeigt. Die Berechnung bleibt gleich. Rufen Sie make auf und vergleichen Sie die ausgeführten Befehle.
int addiere(int a, int b) {
    int ergebnis = a + b;
    return ergebnis;
}
  1. Fügen Sie innerhalb des Include-Schutzes von calc.h einen kurzen Kommentar hinzu, speichern Sie die Datei und rufen Sie erneut make auf. Erklären Sie den Unterschied zum vorherigen Durchlauf anhand der Voraussetzungen.

Ihr Ergebnis: Sie bauen den Rechner mit make und erklären, welche Schritte nach einer Änderung nötig sind.

3. Abschluss: Die Aufteilung im Spielgerüst wiedererkennen

Öffnen Sie das vorbereitete Spielgerüst für die Abschlussaufgabe. Dieses Material wird erst hier benötigt und stammt aus dem folgenden Kapitel Datenstrukturen. Orientieren Sie sich an Dateinamen, include-Anweisungen und Funktionsnamen.

  1. In welcher Datei steht main?
  2. In welcher Datei sollen Sie eigene Funktionen für Textausgabe und Darstellung entwickeln?
  3. Wo werden die Deklarationen bereitgestellt, über die das Gerüst diese Funktionen aufruft?
  4. Woran erkennen Sie im Makefile, welche Quelldateien zum Programm gehören?

Vergleichen Sie die Aufgaben von main.c, calc.c und calc.h mit den entsprechenden Dateien des Spielgerüsts. Für diese Zuordnung genügt das Lesen. Das Spielfeld entwickeln Sie im folgenden Kapitel.

Hinweise

make meldet missing separator

Prüfen Sie, ob die Befehlszeilen mit einem Tabulator beginnen. Der Download enthält die passenden Tabulatoren bereits.

Änderungen verfolgen

Suchen Sie den Namen der geänderten Datei rechts vom Doppelpunkt. Welche Ziele hängen unmittelbar davon ab? Welche weiteren Ziele benötigen diese wiederum?

Im Spielgerüst orientieren

Suchen Sie nach main, text_ausgeben und zeichne. Im Makefile stehen die Quelldateien unter QUELLEN. Das Gerüst verwendet dieselbe Grundidee mit zusätzlichen Bibliotheken und Zeichenfunktionen.

Selbstkontrolle

Beobachtungen beim Bauen

Seit dem erfolgreichen Build keine Änderung.Vorhandene Ergebnisse weiterverwenden.
Nur calc.c geändert.calc.o neu erzeugen, danach linken.
calc.h geändert.Beide Objektdateien neu erzeugen, danach linken.

Auch die Änderung eines Kommentars kann hier einen Build auslösen. make prüft Zeitstempel und eingetragene Abhängigkeiten. Es bewertet nicht, ob sich das Verhalten des C-Programms geändert hat.
