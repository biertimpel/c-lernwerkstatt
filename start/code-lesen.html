Code lesen

Lernziele

  • Die Ausgabe eines kurzen C-Programms vorhersagen.
  • Grundlegende Programmteile und ihre Aufgaben erkennen.
  • Textausgabe und Berechnung unterscheiden.
  • Die Wirkung einer kleinen Änderung nachvollziehen und überprüfen.
  • Quelltext und ausführbare Datei unterscheiden und die Wirkung einer erneuten Übersetzung erklären.

Theorie und Hintergrund

Die Anweisungen in main laufen in diesem Beispiel nacheinander ab. Ein Aufruf von printf gibt Text und gegebenenfalls berechnete Werte aus.

  • Text in doppelten Anführungszeichen steht für eine Zeichenfolge. Eine darin geschriebene Rechnung bleibt Text.
  • Ein Ausdruck wie 7 + 5 außerhalb der Anführungszeichen berechnet einen Wert.
  • %d ist in der Ausgabe ein Platzhalter für eine ganze Zahl. Hier setzt printf das Ergebnis des nachfolgenden Ausdrucks ein.
  • \n erzeugt einen Zeilenumbruch.

Bei den übrigen Programmteilen helfen die Folien aus der Einführung in die Programmierung in C. Funktionen und Header behandeln wir später ausführlicher.

Das Programm

Lesen Sie den Quelltext zunächst, ohne das Programm auszuführen. Notieren Sie Ihre Vorhersagen und Begründungen.

#include <stdio.h>

int main(void) {
    printf("Ein einfacher Rechner\n");
    printf("Rechnung: 7 + 5\n");
    printf("Ergebnis: %d\n", 7 + 5);
    printf("Programm beendet.\n");
    return 0;
}

Aufgaben

1. Ausgabe vorhersagen

  • Welche vollständige Ausgabe erwarten Sie? Berücksichtigen Sie die Zeilenumbrüche.
  • In welcher Anweisung berechnet das Programm eine Summe?
  • Warum gibt eine Anweisung 7 + 5 als Text aus, während eine andere das Ergebnis der Rechnung ausgibt?

2. Programmteile erkennen

Beschreiben Sie für jeden der folgenden Programmteile kurz seine Aufgabe. Nutzen Sie bei Bedarf die Einführungsfolien.

  • #include <stdio.h>
  • int main(void) und die zugehörigen geschweiften Klammern
  • die Aufrufe von printf
  • return 0;

3. Eine Änderung nachvollziehen

Ersetzen Sie gedanklich zunächst nur die Anweisung zur Ergebnisausgabe durch diese Zeile:

printf("Ergebnis: %d\n", 7 - 5);
  • Wie lautet die vollständige Ausgabe jetzt?
  • Welche Ausgaben ändern sich, welche bleiben gleich?
  • Welche weitere Zeile muss angepasst werden, damit die angezeigte Rechnung zum berechneten Ergebnis passt?

4. Vorhersagen überprüfen

  1. Laden Sie die Materialien zur Aufgabe herunter. Das Archiv enthält code-lesen.c und ein fertiges Makefile.
  2. Entpacken Sie das Archiv. Öffnen Sie ein Terminal im Ordner mit diesen beiden Dateien.
  3. Übersetzen und starten Sie zunächst das unveränderte Programm: 
    make
./code-lesen
  4. Vergleichen Sie die Ausgabe mit Ihrer Vorhersage aus Aufgabe 1. Klären Sie mögliche Abweichungen.
  5. Ändern Sie anschließend in der C-Datei ausschließlich die Ergebnisausgabe wie in Aufgabe 3 von 7 + 5 zu 7 - 5. Speichern Sie die Datei. Welche Ausgabe erwarten Sie beim nächsten Start?
  6. Rufen Sie zunächst noch nicht make auf, sondern starten Sie nur: 
    ./code-lesen
    Vergleichen Sie die Ausgabe mit Ihrer Vorhersage und dem gespeicherten Quelltext. Wie erklären Sie Ihre Beobachtung?
  7. Rufen Sie jetzt make und danach ./code-lesen auf. Was hat sich verändert? Welche Datei haben Sie bearbeitet, welche ausgeführt?
  8. Passen Sie zuletzt auch den angezeigten Rechnungstext an. Übersetzen und starten Sie das Programm erneut.

Das Makefile verwenden Sie zunächst als bereitgestelltes Werkzeug. Seinen Aufbau behandeln wir später im Kurs.

Was bedeutet das für Sie? Eine andere Person schickt Ihnen ein fertiges Programm und die zugehörige C-Datei: „Schauen Sie sich den Quelltext ruhig an und probieren Sie das Programm aus.“ Der Quelltext sieht verständlich und unauffällig aus.

  • Wissen Sie damit bereits, was die mitgelieferte ausführbare Datei beim Starten tut? Begründen Sie Ihre Antwort mit Ihrer Beobachtung aus dieser Aufgabe.
  • Sie möchten eine ausführbare Datei erhalten, die aus dem von Ihnen gelesenen Quelltext erzeugt wurde. Wie gehen Sie vor?
  • Formulieren Sie einen Merksatz: Worauf wollen Sie künftig achten, bevor Sie ein fremdes Programm ausführen?

Zusatzaufgabe

Ändern Sie das Programm so, dass es 8 + 6 berechnet und die passende Rechnung samt Ergebnis ausgibt. Notieren Sie die erwartete Ausgabe vor dem Ausführen.

Hinweise

Hinweis zur Ausgabe

Gehen Sie die Aufrufe von printf von oben nach unten durch. Schreiben Sie die jeweilige Ausgabe auf. Bei \n beginnt die nächste Ausgabe in einer neuen Zeile.

Hinweis zu Text und Rechnung

Vergleichen Sie "7 + 5" mit 7 + 5. Die Anführungszeichen bestimmen, ob eine Zeichenfolge oder ein Rechenausdruck vorliegt. Bei der Änderung in Aufgabe 3 bleibt der Text der vorangehenden Anweisung zunächst unverändert.

Hinweis zu Programmabschluss und Übersetzung

return 0; beendet hier main und meldet einen erfolgreichen Abschluss. Die Null erscheint dadurch nicht als zusätzliche Bildschirmzeile.

Nach einer gespeicherten Änderung am Quelltext müssen Sie erneut make aufrufen, damit die ausführbare Datei zur Änderung passt.

Wenn eine Frage offen bleibt, notieren Sie Ihre Erwartung, Ihre Beobachtung und Ihre bisherigen Versuche. Nutzen Sie diese Angaben für die gemeinsame Klärung in der Betreuung.

Selbstkontrolle

Vergleichen Sie mit den Lösungen, nachdem Sie Ihre eigenen Antworten notiert haben.

Lösung zu Aufgabe 1: ursprüngliche Ausgabe 
Ein einfacher Rechner
Rechnung: 7 + 5
Ergebnis: 12
Programm beendet.

Die Anweisung mit "Rechnung: 7 + 5\n" enthält nur den auszugebenden Text. In printf("Ergebnis: %d\n", 7 + 5); steht die Rechnung außerhalb der Anführungszeichen. Ihr Ergebnis ersetzt %d.

Lösung zu Aufgabe 3: geänderte Rechnung

Nach der Änderung ausschließlich der Ergebnisausgabe erscheint:

Ein einfacher Rechner
Rechnung: 7 + 5
Ergebnis: 2
Programm beendet.

Nur das berechnete Ergebnis hat sich geändert. Der angezeigte Rechnungstext stammt aus einer anderen Anweisung und bleibt zunächst gleich. Für eine passende Anzeige müssen beide Zeilen lauten:

printf("Rechnung: 7 - 5\n");
printf("Ergebnis: %d\n", 7 - 5);
Lösung zur Zusatzaufgabe

Passen Sie den Rechnungstext auf 8 + 6 und den Rechenausdruck auf 8 + 6 an. Die Ergebnisausgabe lautet dann Ergebnis: 14.

Lösung zu Aufgabe 4: Quelltext und ausführbare Datei

Beim Start ohne erneutes Übersetzen erscheint weiterhin Ergebnis: 12. Sie haben code-lesen.c geändert, führen aber die zuvor erzeugte Datei code-lesen aus. Diese wird durch das Speichern des Quelltexts nicht automatisch verändert.

Nach erfolgreichem Übersetzen mit make erscheint Ergebnis: 2. Der angezeigte Rechnungstext bleibt zunächst 7 + 5, bis Sie auch diese Zeile anpassen und erneut übersetzen.

Die entscheidende Erkenntnis: Eine neben dem Programm liegende C-Datei garantiert nicht, dass die ausführbare Datei aus genau diesem Quelltext erzeugt wurde. Sie könnte aus einer älteren oder einer ganz anderen Fassung stammen.

Wenn Sie den gelesenen Quelltext selbst übersetzen, erzeugen Sie daraus Ihre eigene ausführbare Datei. Sie müssen sich dann nicht auf die behauptete Herkunft der mitgelieferten Programmdatei verlassen. Auch selbst übersetzter Quelltext kann allerdings Fehler oder schädliche Anweisungen enthalten. Ein möglicher Merksatz lautet: „Beiliegender Quelltext ist kein Nachweis dafür, was eine fremde Programmdatei ausführt.“
