Aufgabe 1

Ihr erstes C-Programm

Ergänzen Sie das kleine Programmgerüst und probieren Sie aus, wie sich die Ausgabe verändert.

Lernziele

  • Ein vorgegebenes C-Programmgerüst gezielt ergänzen.
  • Eine Textausgabe verändern und das Ergebnis überprüfen.
  • Die vier Grundrechenarten mit ganzen Zahlen verwenden.
  • Beobachten, wie sich die Division ganzer Zahlen auf das Ergebnis auswirkt.

Theorie und Hintergrund

Ein Programm besteht aus Anweisungen. In dieser Aufgabe ergänzen Sie zunächst ein vorgegebenes Programmgerüst. Die übrigen Bestandteile lernen Sie im weiteren Verlauf kennen.

Mit printf können Sie Text und Zahlen ausgeben. Text steht in doppelten Anführungszeichen. \n erzeugt einen Zeilenumbruch. %d dient als Platzhalter für eine ganze Zahl.

Variablen wie a und b halten Werte bereit, mit denen gerechnet werden kann. Die Operatoren +, -, * und / stehen für die vier Grundrechenarten.

Bringen Sie Ihr Programm zum Sprechen.

  1. Ersetzen Sie TODO im Programm durch Hello World.
  2. Lassen Sie \n stehen. Es sorgt für einen Zeilenumbruch.
  3. Klicken Sie auf Ausgabe ansehen. Verändern Sie danach den Text und probieren Sie erneut.
Soll-Ausgabe
Hello World
