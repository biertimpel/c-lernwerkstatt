Lernziele

  • Benötigte Parameter und passende Rückgabetypen bestimmen.
  • Deklaration, Definition und Aufruf einer Funktion unterscheiden.
  • Mit return einen Wert zurückgeben und den Funktionsaufruf beenden.
  • Eine Hilfsfunktion in zwei unterschiedlichen Funktionen verwenden.
  • Eine Ausgabefunktion ohne Rückgabewert schreiben.
  • Lokale Variablen und Parameter von einer globalen Konstante unterscheiden.

Theorie und Hintergrund

Eine Schnittstelle festlegen

Eine Funktionsdeklaration macht den Namen, den Rückgabetyp und die Parameter einer Funktion bekannt. Sie enthält noch keinen Funktionskörper:

int addiere(int links, int rechts);

Der Rückgabetyp int beschreibt hier das Ergebnis. Die Parameter links und rechts sind die beiden Zahlen, mit denen die Funktion arbeitet. Jeder Parameter hat einen eigenen Datentyp. Diese Angaben bilden die Schnittstelle der Funktion.

Eine Funktion definieren und aufrufen

Die Definition enthält zusätzlich den Funktionskörper mit den auszuführenden Anweisungen. Beim Aufruf übergeben Sie konkrete Werte, die Argumente:

#include <stdio.h>

int addiere(int links, int rechts) {
    return links + rechts;
}

int main(void) {
    int a = 4;
    int b = 7;
    int summe = addiere(a, b);
    printf("Summe: %d\n", summe);
    return 0;
}

Beim Aufruf addiere(a, b) erhält links den Wert von a und rechts den Wert von b. Die Position entscheidet über die Zuordnung. Das Ergebnis 11 wird in summe gespeichert. Erst printf macht es auf dem Bildschirm sichtbar.

Was bedeutet return?

return ist eine Anweisung, die den aktuellen Funktionsaufruf beendet und zum aufrufenden Programmteil zurückführt. Hinter return kann der Wert stehen, der an den Aufrufer zurückgegeben werden soll.

In addiere wird zuerst links + rechts berechnet. return gibt das Ergebnis an main zurück. Dort wird es in summe gespeichert und anschließend die nächste Anweisung ausgeführt. Anweisungen, die innerhalb desselben Aufrufs nach einem ausgeführten return stehen, werden nicht mehr ausgeführt.

Der zurückgegebene Wert muss zum Rückgabetyp passen. Eine int-Funktion gibt hier eine ganze Zahl zurück, eine double-Funktion kann ein Ergebnis mit Nachkommastellen liefern.

Lokale Variablen und übergebene Werte

Im Beispiel gehören a, b und summe zu main. Die Parameter links und rechts gehören zu addiere. Sie erhalten Kopien der übergebenen Werte. Würde addiere den Parameter links verändern, bliebe die Variable a in main unverändert.

Der Name einer lokalen Variable kann nur in ihrem zugehörigen Block verwendet werden. Die hier verwendeten lokalen Variablen und Parameter werden für den jeweiligen Aufruf angelegt. Nach dem Ende dieses Aufrufs stehen sie nicht als gespeicherte Variablen für den nächsten Aufruf zur Verfügung. Ein benötigtes Ergebnis geben Sie deshalb mit return zurück.

Eine Funktion ohne Rückgabewert

Der Rückgabetyp void bedeutet, dass eine Funktion keinen Wert an ihren Aufrufer zurückgibt. Ihre Ausgabefunktion kann beispielsweise Text anzeigen, ohne ein berechnetes Ergebnis zurückzuliefern. Sie endet am Ende des Funktionskörpers oder vorzeitig mit return;.

Benötigt eine Funktion keine Parameter, können Sie bei ihrer Definition die Klammern leer lassen:

int meine_funktion() {
    return 4;
}

Der Aufruf lautet meine_funktion(). Auch eine Schreibweise mit void in der Parameterliste ist möglich: int meine_funktion(void). Dieses void bedeutet „keine Parameter“. Es ändert nichts am Rückgabetyp int.

main ist der Einstieg in unser Programm. Für diese besondere Funktion behalten die bereitgestellten Programme die bekannte Schreibweise int main(void) bei.

Eine globale Größe verwenden

Eine Variable außerhalb aller Funktionen wird als globale Variable bezeichnet. Ihr Name kann ab der Deklaration in den nachfolgenden Funktionen derselben Datei verwendet werden. Ihr Speicher besteht während der gesamten Programmausführung. Sie muss diesen Funktionen deshalb nicht als Parameter übergeben werden.

const double lieferkosten = 2.50;

Die Lieferkosten bleiben für alle Bestellungen gleich. Mit const legen wir fest, dass dieser Wert nach dem Anlegen nicht mehr durch eine Zuweisung verändert werden darf. Wir verwenden ihn damit als globale Konstante. Schreiben Sie die Deklaration unter #include und vor die erste Funktion.

Anzahl und Einzelpreis gehören dagegen zur jeweiligen Bestellung. Sie bleiben lokale Variablen in main und werden als Argumente übergeben. Auch der berechnete Warenwert bleibt ein lokaler Wert der jeweiligen Funktion.

Reihenfolge in der C-Datei

Beim Übersetzen verarbeitet der Compiler die Deklarationen und Definitionen im Quelltext von oben nach unten. An einer Aufrufstelle muss er den Namen und die Schnittstelle der aufgerufenen Funktion bereits kennen. Steht main vor einer selbst geschriebenen Funktion und fehlt auch eine vorherige Deklaration, ist diese Funktion beim Aufruf noch nicht bekannt.

Wir schreiben deshalb zuerst die gemeinsame Hilfsfunktion, danach die Funktionen, die sie aufrufen, anschließend die Ausgabefunktion und zuletzt main. Eine Definition macht die Funktion zugleich bekannt. Zusätzliche einzelne Deklarationen am Dateianfang sind bei dieser Reihenfolge nicht nötig.

Die Reihenfolge im Quelltext ist nicht die Reihenfolge des Programmstarts. Die Ausführung Ihres Programmcodes beginnt in main. Bei einem Funktionsaufruf werden deren Anweisungen ausgeführt, danach geht es beim Aufrufer weiter. Das sehen Sie auch im Beispiel mit addiere.

Überlegen Sie für jede Funktion, welche Werte sie benötigt und welchen Datentyp diese haben. Welches Ergebnis liefert sie zurück und welcher Rückgabetyp passt dazu? Welche Funktion benötigt keinen Rückgabewert?

Notieren Sie passende Deklarationen. Versuchen Sie dies zunächst selbst. Falls Sie unsicher sind, öffnen Sie die zugehörige Deklarationshilfe.

Deklarationshilfe: berechne_warenwert

Die Anzahl ist eine ganze Zahl. Der Preis pro Artikel und der berechnete Warenwert können Nachkommastellen haben.

double berechne_lieferpreis(int anzahl, double einzelpreis);

Die Funktion erhält die Bestelldaten. Die festen Lieferkosten stehen über die globale Konstante zur Verfügung.

Deklarationshilfe: berechne_abholpreis
double berechne_abholpreis(int anzahl, double einzelpreis);

Die Funktion erhält die Bestelldaten und liefert den Preis nach Abzug des Rabatts.

void gib_preise_aus(double lieferpreis, double abholpreis);

Die fertigen Preise sind Parameter. Die Funktion zeigt sie an und liefert keinen Wert zurück.

Zusatzaufgabe: Eingaben mit scanf

Ersetzen Sie die festen Anfangswerte in main durch Tastatureingaben. Fragen Sie zunächst nach der Anzahl der Artikel und danach nach dem Einzelpreis pro Artikel. Anschließend sollen dieselben Funktionen beide Preise berechnen und ausgeben.

So können Sie einen Preis einlesen:

double einzelpreis = 0.0;
printf("Einzelpreis pro Artikel in Euro: ");
scanf("%lf", &einzelpreis);

printf zeigt wie bisher nur den Text in Anführungszeichen an. scanf liest anschließend Ihre Eingabe. Der Formattext "%lf" gibt an, dass eine Zahl für eine double-Variable eingelesen werden soll. Nach dem Komma steht mit &einzelpreis, wo diese Zahl gespeichert werden soll. Geben Sie zum Beispiel 9.50 ein und bestätigen Sie mit der Eingabetaste.

Für die Anzahl benötigen Sie eine int-Variable. Verwenden Sie dafür entsprechend scanf("%d", &anzahl);. Ergänzen Sie davor eine passende Eingabeaufforderung mit printf.

Verwenden Sie hier zunächst gültige Zahleneingaben wie 3 und 9.50. Wie Sie prüfen, ob das Einlesen funktioniert hat und ob die Werte sinnvoll sind, ergänzen Sie auf der nächsten Seite.

Hinweise

Zu b: Einen Rückgabewert weiterverwenden

Speichern Sie das Ergebnis eines Funktionsaufrufs zunächst in einer lokalen Variable. Mit diesem Wert können Sie anschließend weiterrechnen:

double warenwert = berechne_warenwert(anzahl, einzelpreis);

warenwert enthält hier bereits den Gesamtwert aller Artikel. Multiplizieren Sie diesen Wert nicht erneut mit der Anzahl.

Zu b: Eine feste Vorgabe gemeinsam zugänglich machen

Deklarieren Sie const double lieferkosten = 2.50; außerhalb aller Funktionen. In der Lieferpreisfunktion können Sie dann den Namen lieferkosten verwenden. Anzahl und Einzelpreis übergeben Sie weiterhin als Parameter.

Zur Zusatzaufgabe: Eine ganze Zahl einlesen

scanf liest eine Eingabe und speichert sie in einer Variable. Legen Sie diese zunächst an:

int anzahl = 0;
printf("Anzahl der Artikel: ");
scanf("%d", &anzahl);

%d steht hier für eine ganze Zahl. Das & übergibt die Speicheradresse der Variable, damit scanf den gelesenen Wert dort ablegen kann. Speicheradressen und Pointer behandeln wir später ausführlich.

Zur Zusatzaufgabe: Einen double-Wert einlesen

Für eine Variable vom Typ double verwendet scanf den Platzhalter %lf:

double einzelpreis = 0.0;
printf("Einzelpreis pro Artikel in Euro: ");
scanf("%lf", &einzelpreis);

Beachten Sie das & und verwenden Sie beim Eingeben einen Punkt als Dezimalzeichen.

Selbstkontrolle

Mögliche Lösung: Funktionen und globale Lieferkosten

Vergleichen Sie nach einem eigenen Versuch. Andere sinnvolle Lösungen sind möglich.

#include <stdio.h>

const double lieferkosten = 2.50;

double berechne_warenwert(int anzahl, double einzelpreis) {
    return anzahl * einzelpreis;
}

double berechne_lieferpreis(int anzahl, double einzelpreis) {
    double warenwert = berechne_warenwert(anzahl, einzelpreis);
    return warenwert + lieferkosten;
}

double berechne_abholpreis(int anzahl, double einzelpreis) {
    double warenwert = berechne_warenwert(anzahl, einzelpreis);
    return warenwert * 0.90;
}

void gib_preise_aus(double lieferpreis, double abholpreis) {
    printf("Lieferpreis: %.2f Euro\n", lieferpreis);
    printf("Abholpreis: %.2f Euro\n", abholpreis);
}

int main(void) {
    int anzahl = 3;
    double einzelpreis = 9.50;

    double lieferpreis = berechne_lieferpreis(anzahl, einzelpreis);
    double abholpreis = berechne_abholpreis(anzahl, einzelpreis);
    gib_preise_aus(lieferpreis, abholpreis);
    return 0;
}
