Teilaufgaben und Verantwortlichkeiten finden

Aus einer Beschreibung wird ein eigener Entwurf.

1. Zusammengehöriges erkennen

Eine gute Teilaufgabe lässt sich verständlich beschreiben. Ihr Name erklärt eine Verantwortung, nicht nur ihre Position im Ablauf. Eine Funktion namens „Schritt 2“ bleibt unklar, sobald die Reihenfolge geändert wird.

Gute Zerlegung bedeutet weder „alles in main“ noch „jede Zeile in eine eigene Funktion“. Sinnvoll ist eine Grenze, wenn der Baustein unabhängig erklärt, verwendet, geprüft oder geändert werden kann. Ein kleiner Entwurf darf klein bleiben.

Aufgabe: Einen eigenen Lösungsentwurf skizzieren

Nehmen Sie Ihre Beschreibung von Version 1. Identifizieren Sie zusammengehörige Aufgaben, geben Sie ihnen eigene Namen und zeichnen Sie auf, welche Informationen zwischen ihnen fließen. Markieren Sie, wo eine Entscheidung getroffen und wo lediglich ein Ergebnis dargestellt wird.

Wählen Sie selbst die Darstellungsform: kurze Absätze, eine Tabelle oder beschriftete Kästen und Pfeile. Noch werden keine C-Signaturen verlangt. Notieren Sie zu jeder eingezeichneten Grenze, warum sie Ihnen nützlich erscheint.

Denkhilfe

Stellen Sie sich vor, nur der Wortlaut einer Meldung ändert sich. Würde sich dadurch auch die fachliche Entscheidung ändern müssen? Oder eine Sensorgrenze ändert sich: Wo wäre diese Regel in Ihrem Entwurf zu finden?

2. Den Entwurf erklären und hinterfragen

Erklären Sie Ihren Entwurf einer anderen Person oder der Betreuung. Lassen Sie sich anschließend erklären, was die einzelnen Bausteine nach deren Verständnis tun. Wo die Erklärungen auseinandergehen, präzisieren Sie Ihre Beschreibung.

  • Hat jede Aufgabe eine erkennbare Verantwortung?
  • Kann man für die fachliche Entscheidung ein Ergebnis vorhersagen, ohne erst eine Bildschirmausgabe interpretieren zu müssen?
  • Wer benötigt welche Daten? Wird eine Information unnötig an alle Bausteine weitergereicht?
  • Steht dieselbe fachliche Regel an mehreren Stellen?

Entwerfen Sie kurz eine alternative Aufteilung. Wählen Sie zwischen beiden und begründen Sie einen konkreten Vor- und Nachteil. Sie müssen nicht vorsorglich alle späteren Erweiterungen ermöglichen.

Selbstkontrolle: Woran erkennen Sie einen tragfähigen Entwurf?

Ihre Aufgabenbeschreibung wird vollständig abgedeckt, Informationen haben nachvollziehbare Wege und keine benötigte Entscheidung bleibt „irgendwo im Programm“. Eine andere Person versteht die Verantwortlichkeiten. Unterschiedliche Aufteilungen können diese Kriterien erfüllen; die Übereinstimmung mit einer Musterzeichnung ist nicht das Ziel.

Ihr Ergebnis: Eine eigene Entwurfsskizze mit Namen, Datenfluss und einer begründeten Entscheidung zwischen zwei Varianten. Überarbeiten ist erlaubt und erwünscht!
