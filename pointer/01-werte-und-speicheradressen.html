Werte und Speicheradressen untersuchen

Lesen und schreiben Sie über Pointer und unterscheiden Sie Werte von Adressen.

1. Eine Adresse speichern und benutzen

Eine Variable hat einen Wert und liegt an einer Adresse im Speicher. Mit &var erhalten Sie die Adresse von var. Ein Pointer kann diese Adresse speichern. Man sagt: Der Pointer zeigt auf die Variable. Sie ist sein Ziel.

int var = 10;
int *p = &var;     // p speichert die Adresse von var
int vorher = *p;   // Wert am Ziel lesen: 10
*p = 20;           // Wert am Ziel schreiben: var ist jetzt 20

In der Deklaration int *p gehört das Sternchen zum Pointertyp. Im Ausdruck *p bedeutet es: auf das Ziel zugreifen. Auch p ist eine Variable und hat eine eigene Adresse. int **pp = &p; lässt pp auf p zeigen. *pp liefert den Pointer p, **pp den Wert von var.

2. Rückblick: Arrays und Zeichenketten

Eine Funktion mit dem Parameter int werte[] erhält einen Pointer auf das erste Element. Im Funktionskörper liefert sizeof(werte) daher die Größe des Pointers. Berechnen Sie die Elementanzahl dort, wo das ganze Array vorliegt, und geben Sie sie der Funktion mit, beispielsweise als size_t anzahl. Bei einem zweidimensionalen Array braucht die Funktion außerdem die Spaltenzahl im Parametertyp, um zur richtigen Zeile zu gelangen.

Auch ein Zeichenarray wird bei einem Vergleich mit == in einen Pointer auf sein erstes Zeichen umgewandelt. Der Vergleich prüft damit die Adressen. Zwei getrennte Arrays können denselben Text enthalten. strcmp(a, b) == 0 prüft, ob ihre Inhalte bis zum abschließenden Nullzeichen übereinstimmen.

3. Aufgabe a)

  1. Legen Sie int var = 10; und int *p = &var; an. Sagen Sie voraus, was die Ausgaben von var und *p zeigen, und geben Sie beide Werte aus. Vergleichen Sie anschließend die Adressen p und &var.
  2. Schreiben Sie *p = 20;. Geben Sie var erneut aus und erklären Sie die Änderung.
  3. Ergänzen Sie int **pp = &p; und geben Sie **pp aus. Auf welche Variable zeigt pp direkt? Über welche beiden Schritte gelangen Sie zum Wert?

Greifen Sie zwei kurze Versuche aus „Datenstrukturen“ wieder auf: Vergleichen Sie sizeof für ein Zahlenarray beim Aufrufer und für den Array-Parameter in der Funktion. Wie erfährt die Funktion die Elementanzahl? Legen Sie anschließend zwei getrennte Zeichenarrays mit dem Inhalt "Beute" an. Vergleichen Sie die Adressen ihrer ersten Zeichen mit == und den Inhalt mit strcmp. Erklären Sie beide Ergebnisse.

Hinweise

Zu a): Eine Adresse ausgeben

Verwenden Sie printf("%p\n", (void *)p);. Der Platzhalter %p erwartet einen Pointer vom Typ void *. Vergleichen Sie Adressen aus demselben Programmlauf.

Selbstkontrolle

Werte und Adressen

p enthält &var. Nach *p = 20; liefern var, *p und **pp jeweils 20. Im Array-Parameter misst sizeof den Pointer. Zwei getrennte Zeichenarrays haben verschiedene Startadressen; bei gleichem Inhalt liefert strcmp trotzdem 0.
