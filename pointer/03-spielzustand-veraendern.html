Einen bestehenden Spielzustand verändern

Prüfen Sie das Zielfeld und ändern Sie einen laufenden Spielstand über einen Pointer.

1. Lesen, NULL und Lebensdauer

Mit einem Parameter const Spielstand *p kann eine Funktion den Spielstand über p lesen. Eine Zuweisung an p->zuege ist über diesen Pointer nicht erlaubt. So macht die Deklaration sichtbar, welche Funktionen den Spielstand nur lesen.

NULL bedeutet, dass der Pointer auf kein Ziel zeigt. Ist NULL als Eingabe möglich, prüfen Sie das vor dem ersten Zugriff auf das Ziel. Ein Pointer ist nur so lange brauchbar, wie sein Ziel existiert. Der Test auf NULL allein beweist nicht, dass das Ziel noch existiert.

Für das Spiel heißt das: Der Spielstand wird einmal angelegt und bleibt über die Tastendrücke und Zeichenaufrufe hinweg erhalten. Die Eingabe verändert ihn; Zeichnen und Status lesen ihn.

2. Aufgabe c)

Schreiben Sie figur_bewegen. Die Funktion erhält einen Spielstand * und die Änderung der x- und y-Koordinate als int. Übergeben Sie jeweils einen der vier Schritte zu einem benachbarten Feld.

  • Prüfen Sie den Pointer auf NULL, bevor Sie auf ein Feld zugreifen.
  • Bestimmen Sie das Zielfeld und prüfen Sie Spielfeldgrenzen und Wände mit Ihren vorhandenen Abfragen. Prüfen Sie auch, ob das Zielfeld die Tür ist und sie laut Spielstand verschlossen ist. Die Tür startet wie in „Datenstrukturen“ verschlossen und blockiert die Bewegung.
  • Ändern Sie nur bei einer erfolgreichen Bewegung Position und Zugzahl und geben Sie true zurück. Andernfalls geben Sie false zurück.

Passen Sie die Funktion für die Statuszeile an (im Startmaterial spielstand_lesen). Sie soll den Spielstand über const Spielstand * lesen und die bekannte Statuszeile füllen. Passen Sie die Aufrufe an den neuen Parametertyp an. Rufen Sie Bewegung und Status im Textmodus mit der Adresse desselben Spielstands auf. Probieren Sie auch einen Aufruf der Bewegungsfunktion mit NULL.

Hinweise

Zu c): Das Zielfeld prüfen

Berechnen Sie die Zielkoordinaten zunächst in einer eigenen Variable. Prüfen Sie die Grenzen vor einem Zugriff auf das Spielfeld-Array. Solange das Ziel nicht feststeht, müssen Sie weder Position noch Zugzahl im Spielstand ändern.
