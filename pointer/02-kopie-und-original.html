Kopie und Original vergleichen

Verfolgen Sie im Speichermodell, wie sich eine Wertkopie von einer übergebenen Adresse unterscheidet.

1. Was bekommt eine Funktion?

Beim Aufruf einer Funktion bekommt jeder Parameter eine Kopie dessen, was der Aufrufer übergibt. Das kennen Sie schon aus Block 1 und aus „Datenstrukturen“. Entscheidend ist, was übergeben und damit kopiert wird:

  • Sie übergeben einen Spielstand, zum Beispiel s. Dann kopiert C den ganzen Spielstand mit allen Feldern in den Parameter. Die Funktion arbeitet mit ihrer eigenen Kopie. Ändert sie ein Feld, ändert sie nur diese Kopie. Der Spielstand s beim Aufrufer bleibt, wie er war.
  • Sie übergeben die Adresse eines Spielstands, also &s. Dann kopiert C nur diese Adresse in den Parameter. Der Parameter ist ein Pointer vom Typ Spielstand * und enthält dieselbe Adresse wie &s. Er zeigt deshalb auf denselben Spielstand: auf s beim Aufrufer. Ändert die Funktion über diesen Pointer ein Feld, ändert sie s selbst.

Kopiert wird also in beiden Fällen. Der Unterschied ist, ob eine Kopie der Daten entsteht oder eine Kopie der Adresse, unter der die Daten liegen. Das ist wie bei einem Zettel mit einer Hausadresse: Wer eine Kopie des Zettels bekommt, findet trotzdem dasselbe Haus.

Bei einem Pointer p auf einen Spielstand lesen Sie mit p->zuege das Feld zuege. Das ist die Kurzform von (*p).zuege. Die Klammern sorgen dafür, dass zuerst das Ziel bestimmt wird und erst dann das Feld.

So lesen Sie die Speicheransicht

Der Arbeitsspeicher ist in einzelne Bytes unterteilt. Diese Bytes sind fortlaufend durchnummeriert. Die Nummer eines Bytes nennen wir seine Adresse. Die Ansicht unten zeigt einen kleinen Ausschnitt des Speichers, damit Sie verfolgen können, was beim Ausführen eines Programms passiert.

  • Links steht der C-Code. Die hervorgehobene Zeile wird gerade ausgeführt. Mit den Pfeilen oben rechts gehen Sie Schritt für Schritt weiter, darüber steht, was im aktuellen Schritt passiert. Über „Beispiel“ wechseln Sie zwischen vier Programmen: eine Zahl und eine Struktur, jeweils einmal als Kopie und einmal über einen Pointer übergeben.
  • Rechts ist jedes Kästchen ein Byte. Die Zahl darin ist seine Adresse.
  • Eine Variable belegt mehrere aufeinanderfolgende Bytes, ein int hier 4 und ein Pointer 8. Diese Bytes sind gemeinsam umrandet, und in der Umrandung steht der Wert der Variablen. Bei einer Struktur hat jedes Feld seinen eigenen Block. Rechts daneben stehen Name und Größe. Die Adresse einer Variablen ist die Adresse ihres ersten Bytes. Ändert sich ein Wert, ist sein Block farbig hinterlegt.
  • Ein Pointer enthält als Wert eine Adresse. Der Pfeil führt von ihm zu dem Byte, auf das er zeigt.

Das Modell ist vereinfacht: Es beginnt bei Adresse 0 und zeigt nur wenige Bytes. In einem echten Programm sind die Adressen sehr viel größer, wie Sie auf Seite 1 mit %p gesehen haben.

Erklärung anzeigen
Die erste und die dritte Aussage stimmen. Kopiert wird nur die Adresse &s. Der Parameter p zeigt deshalb auf s beim Aufrufer, und jede Änderung über p verändert s selbst. Nach dem return verschwindet nur der Parameter p, die Änderung an s bleibt. Den ganzen Spielstand kopiert C nur, wenn Sie s selbst übergeben.

      

    


    

      
2. Aufgabe: Den Spielstand des Aufrufers verändern

      
Sie brauchen zwei Funktionen, die Sie im Kapitel „Datenstrukturen“ auf der Seite „Ein Spielstand als Datenstruktur“ geschrieben haben:

      
    
        
  • die Funktion, die einen Spielstand im Startzustand liefert. Im Startmaterial heißt sie startzustand.
    • 
        
  • die Funktion aus dem Versuch am Ende jener Seite: Sie erhält einen Spielstand als Wert und erhöht darin die Zugzahl um eins. Im Startmaterial heißt sie zug_zaehlen.
    • 
      

      
Arbeiten Sie mit Ihrem eigenen Programm weiter, heißen Ihre Funktionen vielleicht anders. Setzen Sie dann im folgenden Code Ihre Namen ein. Legen Sie in text_ausgeben einen Spielstand an, rufen Sie die Funktion zum Erhöhen der Zugzahl auf und geben Sie die Zugzahl aus. Notieren Sie vorher, welchen Wert Sie erwarten.

      
Spielstand s = startzustand();
zug_zaehlen(s);
printf("%d\n", s.zuege);

      
Ergänzen Sie eine zweite Funktion zug_zaehlen_original. Sie erhält einen Spielstand * und erhöht das Feld zuege über ->. Rufen Sie sie mit zug_zaehlen_original(&s); auf und geben Sie s.zuege erneut aus. Wie können Sie den Feldzugriff auch mit * und . schreiben? Erklären Sie den Unterschied zwischen den Aufrufen mithilfe der Speicheransicht.

      
Hinweis: Die Adresse eines Spielstands übergeben
startzustand() liefert den Startzustand als Wert. Speichern Sie ihn zuerst in s. &s liefert dann die Adresse dieser Variable. In Ihrer neuen Funktion bezeichnen p->zuege und (*p).zuege dasselbe Feld, wenn der Parameter p heißt.

      
Selbstkontrolle: Ergebnis der beiden Funktionsaufrufe
Nach zug_zaehlen(s) hat s noch 0 Züge. Nach zug_zaehlen_original(&s) steht im selben s die Zahl 1.
