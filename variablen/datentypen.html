Lernziele

  • Beschreiben, dass Bitmuster eine Interpretationsregel benötigen.
  • Die grundlegenden Typen int, char, float, double und bool verwenden.
  • Werte mit passenden Platzhaltern ausgeben.

Theorie und Hintergrund

Dieselben Bits können unterschiedlich gedeutet werden

Werte werden im Speicher als Bits dargestellt. Betrachten Sie diese acht Bits:

01001101
InterpretationsregelBedeutung
Als vorzeichenlose Binärzahl77
Als ASCII-ZeichencodeDer Buchstabe M

Die Bitfolge allein verrät ihre beabsichtigte Bedeutung nicht. Der Datentyp legt fest, wie ein gespeicherter Wert dargestellt und verarbeitet wird. Für Zeichen wird zusätzlich eine Zeichenkodierung wie ASCII verwendet.

Merken Sie sich zunächst: Im Speicher liegen Bits. Ihre Interpretation gehört zu den Regeln unseres Programms. Der Compiler berücksichtigt die Datentypen beim Übersetzen.

Fünf grundlegende Datentypen

TypVerwendungDeklaration
intGanze Zahlenint anzahl = 4;
charEinzelne Zeichencodeschar gruppe = 'A';
floatGleitkommazahlenfloat temperatur = 19.5f;
doubleGleitkommazahlen mit üblicherweise höherer Genauigkeit als floatdouble strecke = 4.75;
boolWahrheitswerte: wahr oder falschbool abgeschlossen = false;

Gleitkommazahlen werden ebenfalls als Bits dargestellt, jedoch nach anderen Regeln als ganze Zahlen. float und double unterscheiden sich insbesondere in ihrer Genauigkeit. Die genaue Darstellung lernen Sie in Rechnerarchitektur kennen.

Verwenden Sie bei Zahlen einen Dezimalpunkt. Das angehängte f in 19.5f kennzeichnet eine Zahl vom Typ float. Einzelne Zeichen stehen in einfachen Anführungszeichen. Auszugebender Text steht in doppelten Anführungszeichen.

Für bool, true und false binden Sie in der hier verwendeten C17-Fassung zusätzlich #include <stdbool.h> ein.

Passende Ausgabe

TypPlatzhalter bei printf
int%d
char%c
float und double%f
boolhier %d: false als 0, true als 1

Mit %.1f geben Sie eine, mit %.2f zwei Nachkommastellen aus. Diese Angabe verändert die Darstellung bei der Ausgabe, nicht den gespeicherten Wert.

Materialien

Programmgerüste und fertige Makefiles herunterladen

Entpacken Sie das Archiv und öffnen Sie ein Terminal im jeweiligen Aufgabenordner. Bearbeiten Sie dort programm.c. Zum Übersetzen und Starten verwenden Sie:

make
./programm

Übersetzen Sie nach einer gespeicherten Quelltextänderung erneut. Den Aufbau der Makefiles behandeln wir später.

Aufgaben

1. Passende Typen wählen

Schreiben Sie zu jeder Information eine passende Deklaration mit Anfangswert:

  • Anzahl der Personen: 4.
  • Temperatur: 19.5. Verwenden Sie dafür float.
  • Streckenlänge: 4.75. Verwenden Sie dafür double.
  • Gruppenkennzeichnung: A.
  • Aufgabe abgeschlossen: falsch.

Bei den beiden Gleitkommazahlen ist der Typ hier vorgegeben, damit Sie beide Schreibweisen kennenlernen. Begründen Sie die übrigen Entscheidungen.

2. Werte speichern und ausgeben

Ergänzen Sie die Deklarationen aus Aufgabe 1 im heruntergeladenen Programmgerüst. Geben Sie alle Werte mit passenden Beschriftungen aus:

Personen: 4
Temperatur: 19.5
Strecke: 4.75
Gruppe: A
Abgeschlossen: 0

Ändern Sie danach abgeschlossen auf true. Sagen Sie die neue Ausgabe vorher, übersetzen Sie erneut und vergleichen Sie.

3. Darstellung verändern

Geben Sie die Temperatur nacheinander mit %f und %.2f aus. Was verändert sich? Wird der Variable dabei ein neuer Wert zugewiesen?

Bei der Bearbeitung: Erklären Sie sich kurz gegenseitig oder der Betreuung, warum die Bits allein noch nicht erklären, was ein Wert bedeutet. Nutzen Sie das Beispiel mit 77 und M. Wenn Ihnen der Zusammenhang unklar ist, fragen Sie jetzt nach.

Hinweise

Zeichen und Wahrheitswerte

Schreiben Sie char gruppe = 'A'; und bool abgeschlossen = false;. Das Wort false steht dabei nicht in Anführungszeichen.

Ausgabe prüfen

Kontrollieren Sie für jede Ausgabe den Typ der Variable und den passenden Platzhalter. Für float und double verwenden Sie bei printf denselben Platzhalter %f.

Selbstkontrolle

Aufgaben 1 und 2: mögliche Lösung
#include <stdio.h>
#include <stdbool.h>

int main(void) {
    int personen = 4;
    float temperatur = 19.5f;
    double strecke = 4.75;
    char gruppe = 'A';
    bool abgeschlossen = false;

    printf("Personen: %d\n", personen);
    printf("Temperatur: %.1f\n", temperatur);
    printf("Strecke: %.2f\n", strecke);
    printf("Gruppe: %c\n", gruppe);
    printf("Abgeschlossen: %d\n", abgeschlossen);
    return 0;
}

Nach der Änderung auf true lautet die letzte Ausgabe Abgeschlossen: 1.

Aufgabe 3: Ausgabeformat

Mit %f erscheint 19.500000, mit %.2f erscheint 19.50. Die Formatangabe weist der Variable keinen neuen Wert zu.

Speicher und Interpretation

Das Muster 01001101 entspricht als vorzeichenlose Binärzahl 77 und als ASCII-Code dem Buchstaben M. Erst die Interpretationsregel legt fest, welche Bedeutung wir damit verbinden.
