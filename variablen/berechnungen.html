Theorie und Hintergrund

Mit Werten rechnen

Die Operatoren +, -, * und / stehen für Addition, Subtraktion, Multiplikation und Division. Sie können feste Zahlen und die Werte von Variablen verwenden:

int anzahl = 3;
double einzelpreis = 9.50;
double gesamtpreis = anzahl * einzelpreis;

Die rechte Seite wird berechnet und das Ergebnis in gesamtpreis gespeichert. Multiplikation und Division gehen vor Addition und Subtraktion. Klammern verändern die Reihenfolge: 2 + 3 * 4 ergibt 14, (2 + 3) * 4 ergibt 20.

Bei Divisionen zählen die beteiligten Typen

Werden zwei ganze Zahlen dividiert, wird ein möglicher Nachkommateil abgeschnitten. 5 / 2 ergibt deshalb 2. Ist mindestens ein Operand eine Gleitkommazahl, entsteht eine Gleitkommarechnung: 5.0 / 2 ergibt 2.5.

double ergebnis = 5 / 2;

Auch hier ergibt die Rechnung zunächst die ganze Zahl 2. Erst danach wird das Ergebnis in der double-Variable gespeichert. Der Datentyp beeinflusst somit auch, welche Rechnung ausgeführt wird.

Aufteilen: Was bekommt jeder, was bleibt übrig?

Sie verteilen 17 Bonbons auf fünf Personen. Jede Person erhält drei ganze Bonbons. Zwei bleiben übrig. Das sind zwei verschiedene Ergebnisse:

int bonbons = 17;
int personen = 5;
int pro_person = bonbons / personen;
int rest = bonbons % personen;

/ liefert hier den Anteil pro Person: 3. % liefert den Rest: 2. Der häufig „Modulo“ genannte Operator berechnet in C den Rest einer Ganzzahldivision. Wir verwenden dafür zunächst nichtnegative Zahlen und einen positiven Teiler.

Der Rest ist bei vielen Aufgaben die gesuchte Information: übrige Sekunden nach vollständigen Minuten, Gegenstände außerhalb voller Kartons oder die Stunde nach einem vollständigen 24-Stunden-Durchlauf.

Beispielsweise sind 125 / 60 vollständige Minuten und 125 % 60 übrige Sekunden zusammen 2 Minuten und 5 Sekunden. Für die vollständige Zeitangabe benötigen Sie beide Ergebnisse.

Durch null darf weder dividiert noch ein Rest mit % berechnet werden.

Aufgaben

1. Rechnungen vorhersagen

Bestimmen Sie zunächst ohne Ausführung:

8 + 3 * 2
(8 + 3) * 2
17 / 5
17 % 5
17.0 / 5

Ergänzen Sie im Ordner 1-ausdruecke ein Programm, das die Ergebnisse ausgibt. Verwenden Sie passende Platzhalter und vergleichen Sie mit Ihren Vorhersagen.

2. Reicht eine double-Variable?

#include <stdio.h>

int main(void) {
    double a = 5 / 2;
    double b = 5.0 / 2;
    printf("a: %.1f\n", a);
    printf("b: %.1f\n", b);
    return 0;
}
  1. Sagen Sie die Ausgabe vorher.
  2. Übersetzen Sie das Beispiel aus 2-division und vergleichen Sie.
  3. Ändern Sie die erste Rechnung so, dass auch a den Wert 2.5 erhält.
  4. Erklären Sie bei Unklarheiten mit der Betreuung, welche Rechnung vor dem Speichern des Ergebnisses ausgeführt wird.

3. Eine gemeinsame Bestellung

Vier Personen bestellen drei Pizzen. Jede Pizza kostet 9.50 Euro, hinzu kommen einmalig 2.50 Euro Lieferkosten.

Ergänzen Sie im Ordner 3-bestellung ein Programm, das die Ausgangsdaten in passenden Variablen speichert, den Gesamtpreis und den Anteil pro Person berechnet und beides mit zwei Nachkommastellen ausgibt:

Gesamtpreis: 31.00 Euro
Pro Person: 7.75 Euro

Verwenden Sie die Variablen in Ihren Rechnungen. Ändern Sie anschließend die Personenanzahl auf 2. Sagen Sie den neuen Anteil vor dem Ausführen vorher.

4. Minuten und Restsekunden

Ergänzen Sie im Ordner 4-zeit ein Programm, das 367 Sekunden in vollständige Minuten und übrige Sekunden umrechnet:

6 Minuten und 7 Sekunden

Verwenden Sie eine Variable für die gesamte Dauer, eine für die Minuten und eine für die Restsekunden. Prüfen Sie anschließend mit 59, 60 und 61 Sekunden. Warum sind gerade diese Werte für die Überprüfung hilfreich?

Zusatzaufgabe: Über Mitternacht hinaus

Es ist 22 Uhr. Fünf Stunden später ist es 3 Uhr am nächsten Tag. Schreiben Sie im Ordner zusatz-uhr ein Programm mit start_stunde und dauer, das die spätere Stunde von 0 bis 23 berechnet. Verwenden Sie % und zunächst nur nichtnegative Werte.

Prüfen Sie außerdem 10 Uhr plus 3 Stunden und 23 Uhr plus 1 Stunde.

Hinweise

Datentypen bei Rechnungen

Bei / ist entscheidend, ob beide Operanden ganze Zahlen sind. Die spätere Speicherung in einer double-Variable ändert eine bereits ausgeführte Ganzzahldivision nicht.

Bestellkosten

Rechnen Sie zunächst anzahl_pizzen * einzelpreis + lieferkosten. Teilen Sie diesen Gesamtpreis danach durch die Personenanzahl.

Zeit und Rest

Mit sekunden / 60 erhalten Sie vollständige Minuten, mit sekunden % 60 den Rest. Für die Uhrzeit sind vollständige Durchläufe von 24 Stunden relevant.

Aufgabe 3: mögliche Lösung
#include <stdio.h>

int main(void) {
    int personen = 4;
    int anzahl_pizzen = 3;
    double einzelpreis = 9.50;
    double lieferkosten = 2.50;

    double gesamtpreis = anzahl_pizzen * einzelpreis + lieferkosten;
    double pro_person = gesamtpreis / personen;

    printf("Gesamtpreis: %.2f Euro\n", gesamtpreis);
    printf("Pro Person: %.2f Euro\n", pro_person);
    return 0;
}

Bei zwei Personen sind es 15.50 Euro pro Person.

Aufgabe 4: Zeit umrechnen
#include <stdio.h>

int main(void) {
    int sekunden = 367;
    int minuten = sekunden / 60;
    int restsekunden = sekunden % 60;
    printf("%d Minuten und %d Sekunden\n", minuten, restsekunden);
    return 0;
}

Zusatzaufgabe: Uhrzeit
#include <stdio.h>

int main(void) {
    int start_stunde = 22;
    int dauer = 5;
    int end_stunde = (start_stunde + dauer) % 24;
    printf("Spaetere Stunde: %d Uhr\n", end_stunde);
    return 0;
}

Die drei späteren Stunden lauten 3, 13 und 0.
