Theorie und Hintergrund

Eine Variable anlegen und verändern

Eine Variable hat einen Namen und einen Datentyp. Über den Namen können Sie ihren Wert verwenden.

int anzahl = 4;

int steht für ganze Zahlen. Mit dieser Anweisung wird anzahl deklariert und mit dem Anfangswert 4 initialisiert. Deklaration bedeutet, eine Variable mit Namen und Datentyp bekannt zu machen. Initialisierung bedeutet, ihr beim Anlegen einen Anfangswert zu geben.

anzahl = 9;
anzahl = anzahl + 1;

Diese Anweisungen weisen der vorhandenen Variable neue Werte zu. Der Typ wird dabei nicht erneut angegeben. Bei der zweiten Zuweisung wird zunächst mit dem bisherigen Wert gerechnet und danach das Ergebnis gespeichert. Am Ende enthält anzahl den Wert 10.

Getrennte Variablen, getrennte Werte

int a = 4;
int b = a;
a = 9;

b erhält den damaligen Wert von a. Anschließend wird nur a verändert: a enthält 9, b weiterhin 4. Beide Variablen stehen für getrennte Speicherbereiche. Gleiche Werte bedeuten nicht, dass es sich um denselben Speicherplatz handelt.

Namen verständlich wählen

Der Name sollte die Bedeutung des gespeicherten Werts beschreiben. In einer Gleichung kann x sinnvoll sein. Für das Ergebnis einer Rechnung passt beispielsweise ergebnis. Wenn mehrere Ergebnisse vorkommen, hilft ein genauerer Name wie ergebnis_subtraktion.

SchreibweiseBeispiel
snake_case: Wörter mit Unterstrichen trennenergebnis_subtraktion
camelCase: neue Wörter groß beginnenergebnisSubtraktion

Wählen Sie eine einheitliche Schreibweise. Verwenden Sie für den Einstieg Buchstaben von a bis z beziehungsweise A bis Z, Ziffern und Unterstriche. Namen dürfen nicht mit einer Ziffer beginnen und keine Leerzeichen enthalten. Groß- und Kleinschreibung werden unterschieden. Schlüsselwörter wie int oder return sind als Namen nicht erlaubt.

Lokale und globale Variablen

Eine innerhalb einer Funktion deklarierte Variable ist lokal. Eine außerhalb aller Funktionen deklarierte Variable wird als globale Variable bezeichnet.

#include <stdio.h>

int globale_anzahl = 3;

int main(void) {
    int lokale_anzahl = 5;
    printf("Global: %d\n", globale_anzahl);
    printf("Lokal: %d\n", lokale_anzahl);
    return 0;
}

globale_anzahl steht außerhalb von main. lokale_anzahl innerhalb. Mehr müssen Sie dazu zunächst nicht verwenden. Die Regeln für Sichtbarkeit und Lebensdauer greifen wir bei „Programmzerlegung, Funktionen und Debugging“ wieder auf. Deklarieren Sie die Variablen der folgenden Aufgaben innerhalb von main.

Materialien

Programmgerüste und fertige Makefiles herunterladen

Entpacken Sie das Archiv und öffnen Sie ein Terminal im jeweiligen Aufgabenordner. Bearbeiten Sie dort programm.c. Zum Übersetzen und Starten verwenden Sie:

make
./programm

Übersetzen Sie nach einer gespeicherten Quelltextänderung erneut. Den Aufbau der Makefiles behandeln wir später.

Aufgaben

1. Werte nachverfolgen

Lesen Sie das Programm zunächst ohne Ausführung:

#include <stdio.h>

int main(void) {
    int a = 4;
    int b = a;
    a = 9;
    printf("a: %d\n", a);
    printf("b: %d\n", b);
    b = a + 2;
    printf("b danach: %d\n", b);
    return 0;
}
  1. Notieren Sie nach jeder Deklaration oder Zuweisung die Werte von a und b.
  2. Sagen Sie die vollständige Ausgabe vorher. Begründen Sie insbesondere den Wert von b nach a = 9;.
  3. Übersetzen und starten Sie das Programm aus dem Ordner 1-werte-nachverfolgen. Vergleichen Sie Ihre Vorhersage mit der Ausgabe.

2. Werte verändern

Bearbeiten Sie das Gerüst im Ordner 2-werte-veraendern. Legen Sie a mit dem Anfangswert 6 an und initialisieren Sie b mit dem Wert von a. Erhöhen Sie danach a um 3 und geben Sie beide Werte aus. Entfernen Sie die übrigen Zuweisungen aus dem ursprünglichen Beispiel.

Notieren Sie Ihre Erwartung und überprüfen Sie sie. Erklären Sie anhand der zwei Speicherbereiche, warum die Variablen am Ende unterschiedliche Werte enthalten.

3. Eigene Variablen verwenden

Ergänzen Sie im Ordner 3-punkte ein Programm mit punkte und bonus. Initialisieren Sie die Variablen mit 10 und 3. Erhöhen Sie punkte um den Wert von bonus und geben Sie den neuen Punktestand aus.

4. Namen verbessern

Im Ordner 4-namen berechnet das Programm eine Bestellung: a ist die Anzahl der Pizzen, b der Einzelpreis, c die einmalige Liefergebühr und d der Gesamtpreis. Benennen Sie die Variablen verständlich um und passen Sie alle Verwendungen an. Die Ausgabe soll gleich bleiben.

Kurzer Blick auf die Deklarationsstelle

Zeigen Sie im Theoriebeispiel auf die globale und die lokale Deklaration. Woran erkennen Sie den Unterschied? Eine eigene Umsetzung mit globalen Variablen ist hier noch nicht erforderlich.

Hinweise

Werte nachverfolgen

Gehen Sie die Anweisungen von oben nach unten durch. Jede Zuweisung verändert nur die Variable auf ihrer linken Seite.

Mit dem bisherigen Wert rechnen
a = a + 3;
punkte = punkte + bonus;
Namen umstellen

Ändern Sie sowohl die Deklaration als auch jede Verwendung eines Namens. Vergleichen Sie nach dem Übersetzen, ob das Ergebnis gleich geblieben ist.

Aufgabe 2: getrennte Werte

Am Ende enthält a den Wert 9 und b den Wert 6. Die Initialisierung von b erzeugt keine dauerhafte Verbindung mit a.

int main(void) {
    int a = 6;
    int b = a;
    a = a + 3;
    printf("a: %d\n", a);
    printf("b: %d\n", b);
    return 0;
}
